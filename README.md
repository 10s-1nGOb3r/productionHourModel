Flight Block Hour Forecasting PipelineA machine learning pipeline designed to forecast daily airline block hours by combining long-term strategic projections with short-term tactical adjustments. The system processes raw flight records, builds synthetic future schedules, and outputs a reconciled dataset optimized for PowerBI visualization that compares forecasted values against realized actuals.   Pipeline Architecture & Execution FlowThe forecasting engine operates in a strict sequential flow, moving from historical data aggregation to long-range forecasting, followed by tactical short-range corrections.dataTrainingCleanAgg_2.py (Historical ETL)Ingests raw historical flight records (dfsBlockML.csv), alongside external business indicators (peakSeasonDB.csv, fuelCrisisDb.csv).   Cleans block times and aggregates operational metrics by calendar date, calculating total flights, total block hours, and active tail count (acOnline).   Generates calculated fields such as 1-day and 7-day lags, and utilization rates.   Outputs the foundational training dataset: output/aggPerDay.csv.   yearlySyntheticSchedule_2.py (Long-Horizon Simulator)Reads the aggregated historical data from the previous year and shifts all calendar dates forward by exactly one year to create a future testing baseline.   Simulates year-over-year operational expansion by applying a 3% multiplier to both total scheduled flights and active aircraft counts.   Re-applies external calendar event tags (peak season, fuel crisis) and outputs output/syntheticSchedule.csv.   longPredictionXgBoostModel_2.py (Strategic Forecasting)Trains an XGBRegressor on the historical dataset using GridSearchCV (5-fold CV) to optimize hyperparameters like learning rate, max depth, and estimators.   Leverages engineered features including cyclical month encodings (sine/cosine) and weekend indicators.   Generates predictions across the synthetic schedule, tagging them as "Strategic", and creates the initial master export: output/blockHourPredictionPBI.csv.   dataTestCleanAgg_2.py (Tactical Plan ETL)Ingests the immediate, published flight schedule (dfsPlanML.csv) to prepare short-term forecasting data.   Aggregates planned block times, active aircraft, and flight counts by date.   Outputs the tactical testing dataset: output/aggForBlockHourMLForecast.csv.   shortPredictionHybridModelXGBoostArima_2.py (Tactical Correction)Trains an expanded XGBoost baseline model on historical data.   Fits an auto_arima model specifically on the XGBoost prediction residuals to capture high-frequency operational autocorrelation and trends.   Generates a hybrid forecast (XGBoost + ARIMA) for the tactical horizon, strictly capping the input at 60 days to protect the ARIMA model from variance degradation.   Overwrites the matching dates in output/blockHourPredictionPBI.csv with these updated figures, tagging them as "Tactical Hybrid".   actualBlockHourForComparisson_2.py (Actuals Reconciliation)Pulls realized block hours for the current calendar year from the historical aggregation.   Merges and overlays these actuals (totalblockhour) directly into the master PowerBI file.   Formats all dates to YYYY-MM-DD and handles empty values to ensure index alignment is mathematically identical for reporting.
